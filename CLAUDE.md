# CLAUDE.md

## Project Summary

Graduate-level "Topics in Artificial Intelligence" course project.
Fine-tune a pretrained ResNet50 to classify four hammer subtypes, then
build a Streamlit demo comparing the baseline (frozen-backbone) model
against the fine-tuned model side-by-side.

**Deliverables:** code/files for the completed project + a screen
recording with voiced-over narration of the working demo.

## Class Labels

```
ball_peen_hammer  claw_hammer  rubber_mallet  sledge_hammer
```

(Alphabetical — this is the canonical class-index order everywhere.)

## Runtime Constraints

- **Inference / demo:** runs locally on the developer's Windows 11
  machine (CPU only). ResNet50 is small enough for this.
- **Training:** will be run on school-provided GPU servers. The
  developer will copy `src/train.py` (and any helpers it imports) to
  the remote machine, run training there, and bring back the weight
  files.
- **Hosting (stretch goal):** after local development is done, deploy
  the Streamlit app online (Streamlit Community Cloud, HuggingFace
  Spaces, or Render) so anyone with a link can try the demo.

## Training Artifacts the Developer Must Return

After running training remotely, bring back these files and place them
in the project root:

```
models/finetuned.pt         # state_dict from fine-tuned training
```

The UI loads this file to run fine-tuned inference.

## Demo UI Spec

The Streamlit app (`app/streamlit_app.py`) must:

1. Display a gallery of ~12 sample images (sourced from the internet,
   NOT from the training or validation data).
2. Let the user click/select one image. Images live in `media/`.
3. Run inference on **both** models (baseline and fine-tuned).
4. Show results **side-by-side**, clearly labeling which model produced
   which output:
   - Top predicted class
   - Confidence score (percentage)
   - Top-3 predictions with confidence scores
5. Include brief explanatory text: the baseline model (stock ImageNet
   ResNet50, no hammer-specific training) produces generic predictions,
   while the fine-tuned model (trained on hammer images) is much more
   effective at subtype discrimination.

## Conventions

- **Seeds:** `random.seed(42)`, `numpy.random.seed(42)`, `torch.manual_seed(42)` at the top of every script that has randomness.
- **Device:** auto-detect (`cuda` if available, else `cpu`). Never hard-code a device.
- **Paths:** all scripts assume they are run from the project root directory.
- **Model saving:** always save `model.state_dict()`, not the full model object.
- **Image transforms:**
  - Train: `RandomResizedCrop(224) → RandomHorizontalFlip → RandomRotation(15) → RandomPerspective → ColorJitter → ToTensor → Normalize(ImageNet)`
  - Val/Test/Inference: `Resize(256) → CenterCrop(224) → ToTensor → Normalize(ImageNet)`
- **Metrics:** accuracy, precision (macro), recall (macro), F1 (macro).
- **No interactive prompts.** Scripts use `argparse` for configuration.

## Implementation Order

Development is ordered so the UI can be built and tested before the
training dataset exists:

1. Project scaffolding (requirements.txt, folder structure)
2. `src/utils.py` — shared transforms, seed, device helpers
3. `src/model.py` — model builder (works without data)
4. `app/streamlit_app.py` — UI with stock ImageNet ResNet50 as placeholder
5. `src/data.py` — DataLoader factory
6. `src/split_dataset.py` — dataset splitter
7. `src/train.py` — training pipeline
8. *User collects dataset and trains remotely*
9. Plug in real weights, final polish
10. (Optional) Deploy to Streamlit Cloud / HuggingFace Spaces
